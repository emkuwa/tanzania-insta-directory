# Tanzania Instagram Directory MVP

This is a simple static web project connected to Supabase to collect Instagram business profiles from Tanzania.

## 🚀 How to Deploy on GitHub Pages

1. Create a GitHub repo and upload all files.
2. Go to **Settings > Pages** in your repo.
3. Set source to `main` branch and root folder `/`.
4. Save and wait a few seconds.
5. Your live site will appear at: `https://yourusername.github.io/repo-name`

## 📦 Tech Stack

- HTML + TailwindCSS
- Supabase (Auth + Database)
- JavaScript (no build tools)

## ✅ Form Fields Collected

- Business Name
- Instagram Handle
- Bio
- Category
- Location
- Email
- Phone
